# \# GOVPORTUGAL01

# 

# Espelho estático NAO OFICIAL do portal do Governo de Portugal, gerado com HTTrack.

# 

# \- Site oficial: https://www.gov.pt/

# \- Fonte original: https://www.gov.pt/

# \- Ferramenta: HTTrack Online (https://httrack.app)

# \- Natureza: export estático do Next.js, apenas para estudo e demonstração

# 

# \## Aviso

# 

# Este projeto NAO é o portal oficial do Governo Português e não tem vínculo com a

# entidade. Todo o conteúdo, marca e identidade visual pertencem ao gov.pt.

# 

# Todas as páginas exibem aviso fixo de espelho não oficial. Nenhum login ou

# autenticação é processado localmente.

# 

# \## Rodar localmente

# 

# &#x20;   npx serve .

# 

# \## Estrutura

# 

# &#x20;   index.html            página inicial

# &#x20;   guias/ servicos/ ...  páginas espelhadas

# &#x20;   \_next/ \_ext/ assets/  bundles, CSS, JS e imagens

# 

# Não edite \_next/static: são bundles minificados. Para tema, use override.css.
